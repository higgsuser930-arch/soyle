# Сөйле — логопедиялық ойындар

Балаларға арналған қазақша логопедиялық жаттығулар мен ойындар (3D Clay дизайн). Таза HTML/CSS/JS.

**Сайт:** https://higgsuser930-arch.github.io/soyle/

## Мүмкіндіктер
- 1-бөлім: микрофон дем шығаруды естиді (гүл ашылады, қауырсын мен қайық жылжиды).
- 2-бөлім: алдыңғы камера айна ретінде қосылады, жаттығу таймермен жүреді.
- 3–6-бөлім: ойындар (3 деңгей), 🎤 арқылы дауыс танып, дұрыс/қате анықталады.
- Түсіндірмелер ElevenLabs дауысымен оқылады (`audio/`), болмаса браузер TTS-і.

## Іске қосу
```
python3 -m http.server 8765   # http://localhost:8765
```
Камера/микрофон тек HTTPS немесе localhost арқылы жұмыс істейді. Дауыс тану — Chrome/Edge.

## Дауысты жаңарту
Мәтін өзгерсе: `node tools/gen_audio.mjs` (жоқ фразаларды ғана жасайды).
